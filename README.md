# Helping Your Boyfriend

Static fan site for the horror visual novel Helping Your Boyfriend. It is not the official game website and it is not affiliated with the developers.

The public pages are:

- `/`
- `/endings/`
- `/phone-number/`
- `/walkthrough/`

The browser player is loaded from `rs/js/game-config.js`. Leave that file as it is unless you are replacing the player on purpose. Official downloads stay on the creator's itch.io page: https://zieelane.itch.io/helping-your-boyfriend

## Publish on GitHub Pages

The site is meant to be served from the repository root at `https://helping-your-boyfriend.github.io/`.
